# 🎮 Blog VideoJuegos - Sitio Web Temático

Proyecto web desarrollado durante mis primeros semestres de formación en programación web.  
Aunque originalmente fue planteado como una actividad académica en Blogger, decidí desarrollarlo completamente con HTML y CSS en lugar de utilizar plataformas prefabricadas.

El objetivo fue crear una experiencia visual inspirada en el mundo de los videojuegos, incorporando diseño temático, secciones informativas, imágenes, ambientación visual y música de fondo para hacer la navegación más dinámica e inmersiva.

---

## 🌐 Contenido del sitio

El sitio incluye diferentes secciones relacionadas con la industria de los videojuegos:

- Historia de los videojuegos
- Evolución de la industria
- Generalidades
- Consolas clásicas
- Empresas importantes del sector
- Juegos favoritos y recomendaciones

---

## 🎨 Características

- Diseño visual personalizado
- Maquetación realizada manualmente
- Navegación entre múltiples páginas
- Ambientación mediante música en loop
- Organización temática del contenido
- Uso de imágenes y secciones tipo portal informativo

---

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3

---

## 📌 Nota

Este proyecto representa una de mis primeras experiencias creando interfaces web y explorando el diseño visual dentro del desarrollo frontend.  
Aunque técnicamente es un proyecto sencillo, refleja mi interés temprano por construir experiencias web más dinámicas y atractivas visualmente.
